# Receipt App Client

This is the client-side application for the Receipt App, built with React and TypeScript. The application allows users to input receipt information and store it on a server.

## Getting Started

To get started with the client application, follow these steps:

1. **Clone the repository**:
   ```bash
   git clone <repository-url>
   cd receipt-app/client
   ```

2. **Install dependencies**:
   ```bash
   npm install
   ```

3. **Run the application**:
   ```bash
   npm start
   ```

The application will be available at `http://localhost:3000`.

## Features

- Input form for adding new receipts.
- Validates receipt information before submission.
- Sends receipt data to the server using Axios.

## Folder Structure

- `src/`: Contains the source code for the client application.
  - `components/`: Contains React components.
  - `services/`: Contains API service functions for making HTTP requests.
  - `types/`: Contains TypeScript interfaces for type definitions.
